# Long Color Picker
Android 颜色选取库

# 使用示例
```xml
<com.longx.intelligent.android.lib.longcolorpicker.ColorPickerView
      android:id="@+id/color_picker_view"
      android:layout_width="match_parent"
      android:layout_height="wrap_content"
      android:layout_marginTop="15dp"
      app:cpv_defaultColor="#000000"
      app:cpv_alphaEnabled="true"
      app:cpv_alphaBarHeight="30dp"
      app:cpv_hueBarHeight="30dp"
      app:cpv_indicatorColor="#FFFFFF"
      app:cpv_indicatorThickness="1dp"/>
```
